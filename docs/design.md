# 硬核钓鱼改版设计文档

> 状态：设计稿 v0.1  
> 适用范围：`@gitsang/dsh-fishing`  
> 目标：把当前“一次性解锁 + 装备毕业”的结构，改成更真实、更有持续决策的挂机钓鱼模型。

## 1. 背景与问题

当前版本的主要问题：

- 地图、等级、商店都接近一次性内容，通关感强。
- 金币只有一次性消耗，后期溢出。
- 鱼竿/配件是指数型上位替代，永远“顶级一套”。
- 鱼种用 `requiredRodId` 硬性绑定鱼竿类型，导致换竿变成换图鉴，而不是换钓法。
- 很多属性不参与实际判定，或 UI 上不可见。

本次改版不通过“数值 buff / 星级 / 声望 / 稀有度”来延长寿命，而是通过：

- 更真实的鱼类习性；
- 多维度环境筛选；
- 消耗型饵料 + 非消耗型假饵；
- 装备“钓重”与鱼体重的真实对抗；
- 更多地图、更多等级解锁商品。

## 2. 设计原则

1. **真实优先**：鱼种是否有概率出现，取决于时间、气温、光照、水深、水域和食物偏好。
2. **鱼竿类型不硬性决定鱼种**：不是“海竿只能钓海鱼”，而是“当前钓法/深度/饵料是否覆盖到它”。
3. **资源分层**：
   - 体力：出钓次数限制，由 token 产生；
   - 饵料：消耗品，每次抛竿消耗；
   - 假饵：非消耗品，仅路亚竿可用；
   - 金币：购买装备、饵料、门票、维修等。
4. **装备的核心指标是“钓重”**：鱼有多重，装备能不能扛住，是上鱼与损坏的核心判定。
5. **不做以下系统**：
   - 自动卖鱼；
   - 金币收益 +x%；
   - 稀有鱼概率 +x%；
   - 鱼饵效率 +x%；
   - 鱼篓容量 +x%；
   - 星级、声望、转生、稀有度、战力评分等非真实系统。

## 3. 核心资源模型

### 3.1 体力（Stamina）

- 原“鱼饵 bait”资源改名为“体力 stamina”。
- token 消耗按固定比例转换为体力：建议先保留 `1M tokens = 1 stamina`，后续可按实际 token 频率调整到 `200k~500k`。
- 体力分两部分消耗：

```text
出钓体力成本 = 当前地图 staminaCost
搏鱼体力成本 = 实际目标鱼按重量折算的 fightStaminaCost
```

- 地图越远、水域越复杂、目标水深越大，`staminaCost` 越高。
- 体型越大的鱼，搏鱼阶段消耗的体力越多；体力不足时大鱼会脱钩或拉不动。
- 抛竿前只需要满足“出钓体力成本”，搏鱼体力在中鱼后实时扣除。
- 体力不足时不能抛竿；体力只用于“出钓行动”，不等于“饵料”。

### 3.2 饵料（Bait）

- 饵料是消耗品，在商店按“数量包”购买，例如“蚯蚓 ×20”。
- 每次抛竿消耗 1 个已选择的饵料。
- 饵料有真实类型，如：蚯蚓、红虫、玉米、麦粒、商品粉饵、小鱼、活虾、螺蛳、动物内脏、昆虫等。
- 飞德竿（沉底）适合使用沉底饵；路亚竿不消耗饵料，而是使用假饵。

### 3.3 假饵（Lure）

- 假饵是非消耗装备，只有路亚竿可以装配。
- 假饵也有类型：亮片、米诺、软饵、铅笔、波趴、VIB、铁板等。
- 假饵不因抛竿次数而消耗，但可通过“是否命中鱼的食物偏好”参与筛选与咬钩判定。

### 3.4 金币

- 金币来源：卖鱼。
- 金币去向：门票、装备、饵料、配件、维修装备。
- 不设置金币收益倍率类升级。

## 5. 鱼种属性模型

### 5.1 数据结构

移除鱼种上的 `requiredRodId` 硬限制，改为以下字段：

```js
{
  id: 'carp',
  name: '鲫鱼',
  icon: 'assets/fish/carp.svg',

  // 重量范围，单位克
  minWeightGrams: 200,
  maxWeightGrams: 800,

  // 搏鱼体力系数：按实际重量折算 fightStaminaCost
  // fightStaminaCost = ceil(fishWeightKg / staminaPerKg)
  staminaPerKg: 2,

  // 活跃水域：出现在哪些地图
  activeAreas: ['beginner', 'forest_lake', 'pearl_river'],

  // 活跃时间：多段可
  activeTimeRanges: [
    { startHour: 5, endHour: 10 },
    { startHour: 17, endHour: 22 }
  ],

  // 水深范围
  depthRange: { minM: 0.3, maxM: 3 },

  // 水温范围
  waterTempRange: { minC: 10, maxC: 30 },

  // 光照范围：0=黑夜，100=正午晴天；多段可
  lightRanges: [
    { min: 0, max: 30 },
    { min: 60, max: 100 }
  ],

  // 偏好饵料，多选；假饵偏好单独放
  baitIds: ['earthworm', 'dough'],
  lureIds: ['spinner', 'soft_bait'],

  // 基础价格：卖鱼仍按重量/尺寸计算
  baseValue: 12,

  // 图鉴展示信息
  description: '...',
  habitat: '...',
  favoriteBaitText: '蚯蚓、面团'
}
```

### 5.2 筛选规则

当玩家抛竿时，系统用以下条件过滤候选鱼：

1. `map.id ∈ fish.activeAreas`；
2. 当前“地图本地时间”落在任一 `activeTimeRanges`；
3. 当前钓深与 `fish.depthRange` 有交集；
4. 当前水温落在 `waterTempRange`；
5. 当前光照落在任一 `lightRanges`；
6. 使用的饵料/假饵命中 `baitIds` 或 `lureIds`。

**不再使用鱼竿类型硬性过滤鱼种。**

### 5.3 条件匹配

为了“硬核但不完全随机”，可以做“接近中心值加成”：

```text
匹配度 = 时间匹配度 × 温度匹配度 × 光照匹配度 × 深度匹配度
```

- 只要在范围内，就进入候选池。
- 离范围中心越近，`biteChance` 加成越高。
- 超出范围则不进入候选池。

## 6. 装备系统

### 6.1 鱼竿

每根鱼竿至少需要以下关键属性：

```js
{
  id: 'yunchuan_bamboo',
  name: '云川·青竹',
  rodClass: 'hand',        // 仅用于决定能否装假饵/能否调水深
  maxLoadKg: 1.2,          // 钓重
  depthControl: 'adjust',  // adjust | bottom | fixed
  depthRangeM: { min: 0.3, max: 4 },

  // 影响手感的非数值属性
  action: '37调',
  lengthM: 3.6,

  unlockLevel: 1,
  price: 0
}
```

- `rodClass` 不再直接决定“能钓什么鱼”，而是决定：
  - 能否调节水深；
  - 能否装配假饵；
  - 适合的抛投/控线方式（影响咬钩或上鱼概率）。
- `maxLoadKg` 是鱼竿自身能承受的最大鱼重。
- `depthControl`：
  - `adjust`：可手动或自动选择水深；
  - `bottom`：只能沉底，飞德竿属于此类；
  - `fixed`：只能钓固定水层，例如某些浮钓/溪流竿。

### 6.2 配件

配件也引入“钓重”概念。装备的综合钓重取决于整条线组的最弱环节：

```text
综合钓重 = min(
  rod.maxLoadKg,
  line.maxLoadKg,
  reel.maxDragKg,
  hook.maxLoadKg
)
```

配件同时提供不同侧重：

| 配件 | 核心作用 |
|---|---|
| 渔轮 | 泄力/搏鱼，影响 50%~100% 钓重区间的上鱼成功率 |
| 钓线 | 线组钓重上限；线径/隐蔽性影响咬钩 |
| 鱼钩 | 钩尖刺鱼成功率；钩的钓重上限 |
| 浮漂 | 水深呈现/灵敏度，影响部分鱼种咬钩识别 |
| 铅坠 | 沉底/定位水深，影响水流环境下的稳定性 |
| 假饵 | 路亚专用，决定是否进入路亚鱼候选池 |

### 6.3 配件示例

- 渔轮：`maxDragKg` 0.5~15kg；
- 钓线：`maxLoadKg` 0.5~30kg；越细越不挡口但钓重低；
- 鱼钩：`maxLoadKg` 0.3~20kg；不同钩型对应不同饵料/鱼嘴；
- 浮漂：吃铅量与目数影响水深/灵敏度；
- 铅坠：重量影响沉底速度与抗水流能力。

### 6.4 鱼竿扩充

每个竿类不再只有 1~2 条“上位替代”，而是不同“钓重/水层/控饵”组合，例如：

- 手竿：短尺溪流竿、综合竿、大物竿；
- 海竿：远投竿、船竿、重矶竿；
- 路亚竿：直柄/枪柄、L/ML/M/MH 硬度；
- 飞德竿：短节/长节、轻铅/重铅；
- 飞蝇竿：按号数区分；
- 滩钓竿：远投/重滩。

所有商品按 `unlockLevel` 解锁，避免开局直接买到顶配。

## 7. 环境系统

### 7.1 实时环境

为了硬核，环境尽量与现实同步：

- **时间**：按地图城市/时区的真实当前时间。
- **气温**：优先接入真实天气/水温数据；无网络或不可用时，用“纬度 + 月份 + 天气”估算。
- **光照**：根据地图经纬度、日期、当前时间计算太阳高度角，并叠加天气（晴/多云/雨）得到 0~100 的光照值。
- **水深**：玩家选择钓深，范围不能超过地图最大水深。

### 7.2 环境输入源

建议做一个 `environmentProvider`：

```js
{
  getLocalTime(mapId),
  getWaterTemp(mapId, realAirTempC),
  getLightLevel(mapId, weather),
  getWeather(mapId)
}
```

- 有真实天气源时使用真实天气；
- 没有天气源时使用“季节基准温度 + 随机波动”的模拟模式，便于测试。

## 8. 钓鱼流程与判定

### 8.1 抛竿前准备

1. 玩家选择当前地图；
2. 选择鱼竿与配件；
3. 选择水深：
   - `feeder` / `bottom`：水深固定为底部，不可调；
   - 其他竿：可手动输入或选择“自动”，但不能超过 `min(rod.depthRangeM.max, map.maxDepthM)`；
   - 自动模式：在可调范围内自动选择一个能覆盖最多候选鱼的水深。
4. 选择饵料或假饵：
   - 路亚竿：装备假饵，不消耗饵料；
   - 非路亚竿：必须有至少 1 个对应饵料，每次抛竿消耗 1。
5. 检查体力是否足够。

### 8.2 候选鱼筛选

按第 5.2 节规则筛出候选池。

- 如果候选池为空：提示“当前条件没有鱼开口”，不消耗饵料/体力，或只消耗少量体力。
- 如果候选池非空：进入抛竿判定。

### 8.3 咬钩概率

```text
biteChance = baseBiteChance(map)
             + conditionBonus(时间/温度/光照/水深匹配度)
             + baitMatchBonus(命中偏好饵料)
             + tackleBonus(线径/浮漂灵敏度等)
             + rodStyleBonus(钓法是否适合该水层)
```

最终限制在 `0.05 ~ 0.95` 之间。

### 8.4 生成目标鱼与重量

从候选池中按一定权重选一种鱼，再生成个体重量。

- 重量范围由鱼种 `minWeightGrams / maxWeightGrams` 决定。
- 建议用偏向中间偏小的随机分布，而不是均匀分布：
  - 例如 beta 分布或截断正态分布；
  - 大个体出现概率低，但不叫“稀有度”，只是自然体型分布。
- 生成重量后，先计算搏鱼体力成本：

```text
fightStaminaCost = ceil(fishWeightKg / species.staminaPerKg)
```

- 如果当前剩余体力不足以支付 `fightStaminaCost`，大鱼会在搏鱼中脱钩，但不会造成装备损坏。
- 体力足够则继续进入上鱼判定。

### 8.5 上鱼概率（按钓重）

设：

```text
loadRatio = fishWeightKg / 综合钓重
```

判定规则：

| loadRatio | 结果 |
|---|---|
| `<= 0.5` | 咬钩后基本直接成功，默认成功率很高 |
| `0.5 < ratio <= 1.0` | 按鱼竿/渔轮/鱼钩计算上鱼成功率，越接近 1.0 越低 |
| `1.0 < ratio <= 1.2` | 上鱼概率大幅下降，并且有装备损坏风险 |
| `> 1.2` | 直接失败：断线/脱钩/爆竿风险 |

基础公式示例：

```text
if loadRatio <= 0.5:
    hookChance = 1

elif loadRatio <= 1.0:
    hookChance = 0.9 - (loadRatio - 0.5) * 0.8

elif loadRatio <= 1.2:
    hookChance = 0.5 - (loadRatio - 1.0) * 2.5

else:
    hookChance = 0
```

再叠加渔轮泄力、鱼钩锋利度、竿身调性等修正，但上限不超过 0.98。

### 8.6 损坏风险

当 `loadRatio > 1.0` 时：

```text
damageChance = (loadRatio - 1.0) * 100%   // 可配置
```

损坏判定成功后：

- 优先损伤钓线；
- 其次鱼钩/渔轮/鱼竿；
- 对应装备 `condition` 下降；
- `condition` 过低会降低综合钓重或直接失效。

建议增加耐久/维修：

```js
condition: 100 // 0~100，新装备为 100
```

- 装备店提供“维修”服务，按装备价格比例收费。
- 这样可以形成真实金币消耗，同时让“超过钓重”不只是文字提示，而是有后果。

### 8.7 结果结算

- 成功上鱼：进入鱼篓；
- 失败：按失败类型显示“没口 / 脱钩 / 断线 / 爆竿”；
- 获得经验：用于等级成长，等级只用于解锁地图/商店/部分装备；
- 经验不做“倍率 buff”。

## 9. 商店与等级解锁

### 9.1 解锁规则

所有可购买装备增加：

```js
unlockLevel: number
price: number
```

商店只展示 `player.level >= item.unlockLevel` 的商品。

### 9.2 商品分类

| 分类 | 类型 | 是否消耗 |
|---|---|---|
| 鱼竿 | 装备 | 否 |
| 渔轮 | 装备 | 否 |
| 钓线 | 装备 | 否 |
| 鱼钩 | 装备 | 否 |
| 浮漂 | 装备 | 否 |
| 铅坠 | 装备 | 否 |
| 假饵 | 装备（路亚） | 否 |
| 饵料 | 消耗品 | 每次抛竿 1 个 |
| 门票 | 地图通行 | 按天消耗 |
| 维修 | 服务 | 消耗金币 |

### 9.3 更多商品

新增商品不应只是“更高数值”，而是不同“钓重/水层/适用饵料/适用环境”的选择。

示例方向：

- 多种手竿：溪流竿、鲫鱼竿、鲤鱼竿、大物竿；
- 多种海竿：远投竿、船竿、矶竿；
- 多种路亚竿：L、ML、M、MH，适合不同假饵重量；
- 多种钓线：尼龙线、碳素线、PE线，不同钓重/隐蔽性；
- 多种饵料：自然饵与商品饵；
- 多种假饵：亮片、米诺、软饵、波趴、VIB。

## 10. 数值平衡草案

### 10.1 体力

| 项目 | 建议 |
|---|---|
| token → stamina | 先保持 `1M token = 1 stamina` |
| 入门地图 | 1 stamina / 抛竿 |
| 中级地图 | 2 stamina / 抛竿 |
| 高级地图 | 3~5 stamina / 抛竿 |
| 远海/传说级 | 6~10 stamina / 抛竿 |
| 搏鱼体力 | `ceil(fishWeightKg / species.staminaPerKg)` |

### 10.2 钓重与鱼重

- 入门装备综合钓重约 `0.5~2kg`；
- 入门鱼常见 `0.2~0.8kg`；
- 中级装备综合钓重约 `3~8kg`；
- 大型鱼 `10~30kg` 需要高级线组和足够钓重；
- 新手装备遇到大鱼会频繁断线，但不会完全无法遇到“大鱼咬钩”。

### 10.3 等级

- 保留等级系统，但主要作为“解锁地图/商店”的门槛；
- 等级曲线可继续用当前 EXP，也可调高后期所需经验；
- 不新增星级、声望等额外成长线。

## 11. 与当前代码的主要差异

| 项目 | 当前 | 改版后 |
|---|---|---|
| token 资源 | `bait` | `stamina` |
| 每次抛竿消耗 | 1 bait | `map.staminaCost` stamina + 1 饵料（非路亚）/ 假饵不消耗 |
| 鱼竿分类作用 | 硬性过滤鱼种 | 只决定钓法/水深/假饵安装 |
| 鱼种属性 | 地图+rodType | 水域+时间+水深+水温+光照+饵料多选 |
| 鱼竿关键属性 | baseSuccessRate/weightMultiplier/catchMultiplier | 钓重 maxLoadKg、水深控制等 |
| 配件 | 少量固定加成 | 线组钓重、泄力、钩型、灵敏度等 |
| 商店 | 等级只限制地图 | 商品也按等级解锁 |
| 地图 | 12 张 | 扩展至 18~20 张 |
| 耐久/维修 | 无 | 新增（可选但建议） |
| 自动卖鱼/数值 buff | 有想法但不做 | 明确不做 |

## 12. 实施顺序建议

1. **数据层改造**
   - 新增地图、鱼种属性；
   - 新增饵料/假饵数据；
   - 增加商品 `unlockLevel`。

2. **资源改名**
   - `bait` → `stamina`；
   - 增加 `inventory.baits` / `inventory.lures`。

3. **环境系统**
   - 地图本地时间；
   - 气温估算/真实同步；
   - 光照计算；
   - 自动/手动水深。

4. **钓鱼判定**
   - 候选池筛选；
   - 咬钩概率；
   - 重量生成；
   - 钓重比值上鱼判定；
   - 损坏/耐久。

5. **商店与 UI**
   - 等级解锁展示；
   - 饵料数量展示与购买；
   - 假饵装配；
   - 当前环境/水深/候选鱼展示；
   - 装备钓重对比。

6. **地图扩展**
   - 补齐等级空缺地图；
   - 扩充鱼类与装备数据。

> **第一步可以先只做“体力成本”改造**：`bait → stamina`、地图增加 `staminaCost`、鱼种增加 `staminaPerKg`、抛竿和搏鱼分别扣体力。  
> 这个改动不依赖环境/钓重系统也能先落地，能立刻缓解“地图/鱼种无成本、进度过快”的问题。

## 13. 不做清单（防跑偏）

- ❌ 自动卖鱼
- ❌ 金币收益 +x%
- ❌ 稀有鱼概率 +x%
- ❌ 鱼饵效率 +x%
- ❌ 鱼篓容量 +x%
- ❌ 星级 / 声望 / 转生
- ❌ 稀有度颜色 / 稀有度加成
- ❌ 鱼竿类型直接决定能钓什么鱼
- ❌ 一套顶级装备全地图通吃
